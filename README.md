# شفاء — عيادة الكبسولات

لعبة مطابقة ثلاثية فاخرة بطابع طبي: أنت الطبيب، والكبسولات تحمل بودرة دواء متحركة بدقة عالية.

## التشغيل

```bash
cd capsule-care
npm start
```

ثم افتح `http://localhost:4173`

## المحتوى

- كبسولات زجاجية مع محاكاة بودرة متحركة (جسيمات + توهج)
- قصة 8 مرضى عبر عيادات: الحي، الأطفال، الطوارئ، المختبر
- معززات طبية: حقنة صف، بخاخ عمود، نبضة محيط، إعادة ترتيب
- قطع خاصة: صف / عمود / قنبلة / قوس قزح
- حفظ تقدّم محلي ورتب الطبيب
