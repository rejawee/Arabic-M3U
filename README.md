# Arabic-M3U + شفاء

- قائمة IPTV: `Arabic.m3u`
- لعبة المطابقة الطبية: [`capsule-care/`](./capsule-care/)

## رابط اللعبة (عام)

**الرابط الدائم:** https://rejawee.github.io/Arabic-M3U/

> لتفعيله مرة واحدة: GitHub → **Settings** → **Pages** → **Build and deployment** → Source: **GitHub Actions**  
> الكود جاهز على `master` وسworkflow النشر `Deploy Shifa to GitHub Pages` ينشر مجلد `capsule-care/` تلقائياً.

تشغيل محلي:
```bash
cd capsule-care && npm start
```
ثم http://localhost:4173

للنشر الدائم: Settings → Pages → branch `gh-pages` →  
https://rejawee.github.io/Arabic-M3U/
