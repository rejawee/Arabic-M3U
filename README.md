# شفاء — عيادة الكبسولات

لعبة مطابقة ثلاثية فاخرة بطابع طبي: أنت الطبيب، والكبسولات تحمل بودرة دواء متحركة بدقة عالية.

## العب الآن

**https://lie-each-magic-prove.trycloudflare.com**

> رابط مؤقت. الرابط الدائم: **https://rejawee.github.io/Arabic-M3U/**

## تشغيل محلي

```bash
npm start
```

ثم افتح: http://localhost:4173

## GitHub Pages (رابط دائم)

1. في المستودع: **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **`gh-pages`** / folder: **`/`**
4. احفظ، ثم افتح بعد دقيقة:  
   https://rejawee.github.io/Arabic-M3U/

## المحتوى

- كبسولات من صورة المرجع الزجاجية مع بودرة متحركة
- قصة 8 مرضى عبر عيادات: الحي، الأطفال، الطوارئ، المختبر
- معززات طبية وقطع خاصة
- واجهة عربية RTL وحفظ تقدّم محلي
