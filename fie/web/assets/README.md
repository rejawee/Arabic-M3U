# Media assets (demo)

Team crests and player photos under `teams/` and `players/` are downloaded from
[media.api-sports.io](https://media.api-sports.io) for **local UI prototyping**.

## Rules

- Do not redistribute these files as a standalone media pack.
- Production builds should pull images through a **licensed** API-Football / API-Sports plan
  (or another licensed provider) and follow that provider’s terms.
- Prefer caching on your own CDN only when the license allows it.

## Mapping

See `../js/media.js` for team/player IDs and fixture wiring.
